🎬 Movie List App

A simple React-based movie listing application where users can browse movies, search for titles, and view movie details.

🚀 Features
Display movie list
Search movies
Responsive UI
Add/remove favorites
Movie cards with posters
Loading states
Error handling

🛠️ Tech Stack
React
JavaScript
CSS / Tailwind CSS
Axios / Fetch API
TMDB API (or your API)

⚙️ Installation
# Clone repository
git clone <your-repo-link>

# Move into project
cd movie-app

# Install dependencies
npm install

# Start app
npm start
